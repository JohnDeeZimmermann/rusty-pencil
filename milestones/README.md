## How a milestone file is used

1. Read "Goal" and "Done when".
2. Work the numbered tasks top to bottom; tick each one.
3. When every "Done when" item can be shown working, tick the matching lines in
   [`../EXCALIDRAW.md`](../EXCALIDRAW.md).
4. Write decisions that surprised you under "Notes" so the next milestone sees them.
